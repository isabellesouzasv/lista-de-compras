# Quicklist - Lista de Compras

## Sobre o projeto

Aplicação de lista de compras para organizar os itens da semana. A página permite adicionar novos produtos, marcar itens como concluídos e removê-los da lista com uma mensagem de confirmação. O projeto possui validação de formulário, interações acessíveis e layout responsivo. Foi desenvolvido como parte da **formação Full Stack da Rocketseat**.

![Preview do projeto](/assets/screenshot.png)

## Funcionalidades

- Exibição de itens pré-cadastrados na lista de compras.
- Adição de novos itens por meio do campo de texto.
- Limpeza automática do campo após adicionar um item.
- Validação amigável ao tentar adicionar um item vazio.
- Marcação e desmarcação de itens como concluídos.
- Destaque visual para itens concluídos com texto riscado e opacidade reduzida.
- Remoção individual de itens da lista.
- Alerta temporário após a remoção de um item.
- Opção para fechar manualmente o alerta de remoção.
- Layout responsivo para desktop e dispositivos móveis.
- Navegação e controles acessíveis por teclado.
- Suporte à preferência de movimento reduzido do sistema.

## Como executar

Basta abrir o arquivo `index.html` no navegador. Não há dependências ou instalação necessárias.

Para clonar o projeto:

```bash
git clone https://github.com/isabellesouzasv/lista-de-compras.git
cd lista-de-compras
```

Depois, abra o arquivo:

```text
index.html
```
